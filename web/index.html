Five-agent architecture

OrchestratorLangGraph state machine. Routes on retrieval score, generator confidence, claim risk and the remaining latency budget. Plans fast / deep verification, degrades gracefully to "Unverified".
Retrievermultilingual-e5-small + FAISS over Maharashtra GR chunks. Cross-lingual (English question → Marathi evidence).
GeneratorQuantised Llama (GGUF Q4_K_M, llama.cpp, CPU). Grounded prompt with [n] citations and NOT_FOUND abstention; token-probability confidence.
VerifierHeterogeneous cascade: Tier-0 numeric/lexical heuristics (ms) → Tier-1 multilingual mDeBERTa NLI (int8) → Tier-2 deep multi-window / DeBERTa-v3-large NLI only for uncertain claims.
CriticRule-based, auditable taxonomy: numeric fabrication, contradiction, unsupported, citation mismatch, unverifiable, unchecked. Verdict + risk. Detection only, never rewrites.
